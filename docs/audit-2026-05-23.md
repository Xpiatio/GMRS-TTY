## 1. SOLID

### Critical

**Single Responsibility — `MainWindow` (2,357 lines, 86 methods)**
`gmrs_tty/ui/main_window.py`
Simultaneously owns: UI construction, dock lifecycle, service-mode state machine, STT worker lifecycle, spectrometer worker lifecycle, contact management, callsign lookup, journal generation, PTT wiring, theme application, audio monitoring, online indicator refresh, config persistence. Classes already extracted (`TXController`, `RXSession`, `AttendancePanel`) prove the pattern works. Clusters that should become their own classes:
- `_STTLifecycleManager`
- `_SpectrometerManager`
- `_PendingStationManager`
- `_JournalController`

### Warning

**Open/Closed — `make_ptt` factory**
`gmrs_tty/ptt/factory.py:14-26`
Explicit `if mode == "usb_ftdi"` branch; every new PTT type with constructor args forces modification. `_SIMPLE_MODES` dict already demonstrates the open pattern — extend it to a callable-factory dict.

**Single Responsibility — `ConfigDialog.__init__` (>320 lines)**
`gmrs_tty/ui/config_dialog.py:20-330`
Constructor builds every widget, wires signals, fires background thread, handles device callbacks. Factor into `_build_audio_section()`, `_build_ptt_section()`, etc.

**Dependency Inversion — `MainWindow` calls `save_json`/`load_json` directly**
`gmrs_tty/ui/main_window.py:255,1135,1143,1332,1370,1475,1689,1715,1755,1775,2198,2307`
12 call sites. An `AppState` repository with a `save()` method would invert this.

**Interface Segregation — `STTWorker` exposes `self.whisper` / `self.vad_model` as public**
`gmrs_tty/stt/worker.py:93-94`
Documented as public for `MainWindow` to hoist post-stop. A `ModelCache` result struct would decouple this.

### Info

**Liskov — `DeviceQueryThread` overrides `run()` not `_run()`**
`gmrs_tty/ui/worker_base.py:20`
`WorkerBase` promises `_run()` is the extension point; the docstring calls out the workaround but the contract is still broken.

## 6. Security

### Critical

**Gemini API key in URL query string**
`gmrs_tty/ai/gemini_client.py:51`
```python
url = f"{_BASE_URL}/{_MODEL}:generateContent?key={api_key}"
```
Key appears in proxy logs, process-level URL inspection, and crash reports. Fix: pass as `x-goog-api-key` header instead.

**Gemini API key stored as plaintext in `config.json`**
Written world-readable by default. No OS keychain integration. Design limitation — flag for future keyring integration.

### Warning

- **Path traversal in `delete_journal`:** `persistence/journal.py:62-64` — `file_path` loaded from `entry["_file"]` in the JSON; a crafted journal file could point outside `journals/`. Add: `assert Path(file_path).resolve().parent == Path(JOURNALS_DIR).resolve()`
- **`cookies_file` path passed to yt-dlp unvalidated:** `audio/capture.py:13-14` — relative paths like `../../etc/passwd` are silently forwarded. yt-dlp fails to parse non-cookies content but the path should be canonicalized.
- **`traceback.print_exc()` in production:** `tx_controller.py:187` — leaks internal paths and variable values to stdout.
- **`print()` leaks file paths on error:** `json_store.py:12,22` — replace with `logging.warning`.
- **`print()` leaks serial port names:** `ptt/factory.py:19,24`
- **No response-body size limit on Gemini / FCC API calls:** `gemini_client.py:59`, `fcc/crossref.py:138` — `json.loads(resp.read())` buffers entire response unbounded.

### Info

- `whisper_model` used to construct a filesystem path without validation — a crafted `config.json` could cause stat of arbitrary paths. `stt/worker.py:86` — add `re.fullmatch(r'[a-zA-Z0-9._-]+', whisper_model)` guard.
- `voice` config value passed to `PiperVoice.load()` without canonicalization. `tx_controller.py:91`
